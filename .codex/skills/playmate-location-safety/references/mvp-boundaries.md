# MVP Boundaries Reference

Use this reference when a change may expand product scope.

## Required MVP Features

- venue selection
- deal/special price information
- cost calculator
- pre-visit checklist
- Kakao, Apple, and Google login
- trip room creation
- trip invitation
- trip-room location sharing
- venue map and facility search
- saved locker/parking/rental place
- lost item report
- photo/visit record
- visit report or share card

MVP visit report sharing is limited to OS-level sharing or image save. Do not add direct social integrations unless requested.

Venue, facility, and deal data are manually managed with JSON/CSV or seed data during MVP. Do not add admin pages or crawling unless requested.

## Excluded From MVP

Do not add these unless the user explicitly changes scope:

- real-time wait time prediction
- automatic congestion analysis
- AI route optimization
- in-app ticket payment
- official reservation integration
- ranking, points, or complex gamification
- broad social feed or community chat
- unlimited background location tracking
- long-term location history analysis
- discount crawling or automatic collection
