# Docs

이 폴더는 사람과 AI가 같은 기준으로 개발하기 위한 프로젝트 문서 공간입니다.

## 문서 구조

```text
docs/
├─ requirements/    # 요구사항과 MVP 범위
├─ architecture/    # 전체 구조, 폴더 책임, 데이터 흐름
├─ policies/        # 위치, 배터리, 개인정보 정책
├─ ai-rules/        # AI 코딩 규칙
├─ testing/         # 테스트 체크리스트
└─ roadmap/         # MVP 이후 확장 방향
```

## 문서 갱신 원칙

- 기능을 추가하거나 정책을 바꾸면 관련 문서도 함께 갱신한다.
- 문서의 기능명과 코드의 폴더명은 최대한 맞춘다.
- MVP 범위를 바꾸는 경우 `requirements/MVP_SCOPE.md`를 먼저 수정한다.
