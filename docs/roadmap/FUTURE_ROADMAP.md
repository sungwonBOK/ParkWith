# Future Roadmap

## MVP 이후 후보 기능

- 사용자 제보 기반 체감 대기시간
- 위치 기반 구역별 혼잡도 추정
- 장소별 추천 루트
- 가격, 혼잡도, 날씨 기반 방문 추천
- 공식 제휴를 통한 입장권/렌탈/패키지 구매
- 위치 기반 포토존 추천
- 방문 기록 기반 개인화 추천
- 스키장 지원
- 할인 정보 크롤링 또는 자동 수집
- 관리자 페이지

## 대기시간 기능 도입 조건

대기시간 또는 혼잡도 기능은 다음 조건을 만족한 뒤 검토합니다.

- 충분한 활성 사용자 수
- 명시적 위치/분석 동의
- 배터리 소모와 개인정보 리스크를 감당할 수 있는 정책
- 장소별 시설 좌표 데이터 품질
- 잘못된 예측에 대한 사용자 안내 방식

## 제휴/수익화 조건

제휴와 결제는 MVP 이후에 도입합니다.

우선순위:

1. MVP에서는 외부 할인 링크를 수동 관리한다.
2. 사용자가 자주 찾는 장소와 카테고리를 확인한다.
3. 간단한 관리자 페이지 필요성을 검증한다.
4. 할인 정보 크롤링 또는 자동 수집을 검토한다.
5. 제휴사 대시보드 필요성을 검증한다.
6. 공식 예약 또는 결제 연동을 검토한다.
