# Test Checklist

## 공통

- 화면이 정상적으로 열린다.
- 빈 데이터일 때 화면이 깨지지 않는다.
- 네트워크 실패 시 사용자 친화적 에러가 표시된다.
- 사용하지 않는 API key나 개인정보가 로그에 남지 않는다.

## 인증

- 카카오 로그인 진입 흐름이 표시된다.
- Apple 로그인 진입 흐름이 표시된다.
- Google 로그인 진입 흐름이 표시된다.
- 로그아웃 후 일행방/위치 공유 같은 로그인 필요 기능 접근이 제한된다.
- 인증 토큰이 로그에 출력되지 않는다.

## 장소/시설

- 장소 목록이 표시된다.
- 장소가 없을 때 빈 상태가 표시된다.
- 장소 상세 정보를 볼 수 있다.
- 시설 목록을 장소별로 조회할 수 있다.
- 위치 권한이 없어도 시설 지도는 볼 수 있다.

## 일행방

- 사용자가 일행방을 생성할 수 있다.
- 초대 링크 또는 QR로 참여할 수 있다.
- 방장이 방문 시작/종료를 누를 수 있다.
- 방문 종료 후 상태가 `ended`가 된다.

## 위치 공유

- 앱 설치 직후 위치 권한을 요청하지 않는다.
- 방문 시작 후 사용자가 위치 공유를 켤 때 권한을 요청한다.
- 권한 거부 시 대체 안내가 표시된다.
- 위치 공유 OFF 상태에서는 위치를 업로드하지 않는다.
- 방문 종료 후 위치 전송이 중단된다.
- 배터리 절전 모드에서 위치 갱신 주기가 줄어든다.
- 위치 좌표가 로그에 출력되지 않는다.
- 서버에는 이동 경로가 아니라 사용자별 최신 위치만 남는다.

## 사진/분실물

- 사진 업로드 전에 개인정보 안내가 표시된다.
- 사용자는 업로드한 사진을 삭제할 수 있다.
- 분실물 제보는 장소별로 구분된다.
- 방문 리포트는 OS 기본 공유 또는 이미지 저장으로 공유된다.
