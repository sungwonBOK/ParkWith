# MVP Scope

## 목표

MVP의 목표는 대기시간 예측이 아니라, 방문자가 앱을 설치하고 실제 방문 중 계속 열어볼 이유를 만드는 것입니다.

핵심 가치는 다음 세 흐름입니다.

1. 방문 전: 장소 선택, 할인 정보 확인, 총비용 계산, 체크리스트 확인
2. 방문 중: 일행방, 위치 공유, 시설 지도, 락커/주차 위치 저장
3. 방문 후: 사진/방문 기록과 공유용 방문 카드 제공

## 제품명

제품명은 `ParkWith`로 확정합니다. 현재 로컬 폴더명이 다르더라도 문서, 앱 표시명, 패키지명은 `ParkWith` 기준으로 맞춥니다.

## MVP 필수 기능

| 기능 | 상태 | 설명 |
| --- | --- | --- |
| 장소 선택 | 필수 | 놀이공원, 워터파크 장소 목록/검색/상세. 스키장은 MVP 이후 확장 |
| 할인/특가 정보 | 필수 | 입장권, 리프트권, 렌탈, 락커, 주차 등 외부 구매 링크 제공 |
| 총비용 계산기 | 필수 | 인원과 옵션 기준 예상 비용 계산 |
| 방문 전 체크리스트 | 필수 | 장소 유형별 준비물 체크 상태 저장 |
| 일행방 생성 | 필수 | 장소와 날짜 기준 방문방 생성 |
| 일행 초대 | 필수 | 초대 링크 또는 QR 기반 참여 |
| 일행 위치 공유 | 필수 | 방문 세션 중 동의한 사용자만 최신 위치 공유 |
| 지도 기반 시설 검색 | 필수 | 권한이 없어도 시설 지도 조회 가능 |
| 락커/주차 위치 저장 | 필수 | 텍스트와 사진 기반 위치 메모 저장 |
| 분실물 제보 | 필수 | 장소별 분실물/습득물 등록 |
| 사진/방문 기록 | 필수 | 방문 사진과 기록을 일행방 단위로 묶기 |
| 방문 리포트 | 필수 | 공유용 방문 카드 생성. MVP에서는 OS 기본 공유까지만 지원 |

## 인증 방식

MVP 인증은 소셜 로그인을 사용합니다.

- 카카오 로그인
- Apple 로그인
- Google 로그인

일행방, 위치 공유, 저장 위치, 사진, 분실물 제보는 로그인한 사용자를 기준으로 작성자와 권한을 관리합니다.

## 초기 지원 장소

MVP 초기 데이터는 수동으로 관리하며, 다음 장소부터 시작합니다.

워터파크:

- 캐리비안베이
- 오션월드
- 롯데워터파크
- 웅진플레이도시 워터도시

놀이공원:

- 에버랜드
- 롯데월드 어드벤처 서울
- 롯데월드 어드벤처 부산
- 경주월드

스키장은 추후 개발 예정입니다.

## MVP 제외 기능

- 실시간 대기시간 예측
- 실시간 혼잡도 자동 분석
- AI 기반 완전 자동 루트 추천
- 앱 내 티켓 결제
- 공식 예약 연동
- 사용자 랭킹 시스템
- 포인트 보상 시스템
- 복잡한 SNS 피드
- 채팅 기반 전체 커뮤니티
- 무제한 백그라운드 위치 추적
- 장기 위치 기록 분석
- 공식 시설 시스템 연동
- 할인 정보 자동 크롤링

## 방문 세션 상태

MVP에서는 방문 세션 상태를 세 가지만 사용합니다.

```text
not_started
active
ended
```

`paused`는 MVP 이후 확장 후보이며, 현재 구현하지 않습니다.

## 데이터 입력 방식

MVP에서는 장소, 시설, 할인 정보를 JSON/CSV 또는 seed 데이터로 수동 관리합니다.

초기에는 관리자 페이지와 크롤링을 만들지 않습니다. 사용자 검증 이후 운영 필요성이 생기면 간단한 관리자 페이지를 먼저 검토하고, 할인 정보 크롤링은 그 다음 단계로 검토합니다.

## 공유 권한

일행방 안에서 생성된 체크리스트, 저장 위치, 사진, 분실물 제보는 기본적으로 작성자와 같은 일행방 구성원이 볼 수 있습니다.

수정/삭제 권한은 기능별로 다음 기준을 기본값으로 합니다.

- 작성자: 수정/삭제 가능
- 같은 일행방 구성원: 조회 가능
- 같은 일행방 구성원의 수정/삭제 권한은 기능별로 구현 전에 별도 결정
