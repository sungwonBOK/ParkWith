# Data Privacy Policy

## 기본 원칙

개인정보와 위치정보는 최소 수집 원칙을 따릅니다.

## 위치 정보

- 위치 공유는 명시적 동의 후에만 활성화한다.
- 위치는 같은 일행방 참여자에게만 보여준다.
- MVP에서는 위치 이동 경로가 아니라 사용자별 최신 위치만 저장한다.
- 방문 종료 후 개인 식별 가능한 위치 데이터는 삭제하거나 만료 처리한다.
- 위치 좌표는 로그에 남기지 않는다.
- 사용자의 동의 없이 위치 데이터를 분석용으로 사용하지 않는다.

## 인증 정보

- MVP 인증은 카카오, Apple, Google 로그인을 사용한다.
- 서버는 소셜 provider에서 받은 식별자를 내부 `userId`와 연결해 관리한다.
- access token, refresh token, provider token은 로그에 남기지 않는다.
- 인증 정보 저장 방식은 구현 전에 별도 보안 검토를 거친다.

## 사진 정보

- 분실물, 락커, 주차, 방문 기록 사진에는 개인정보가 포함될 수 있다.
- 사진 업로드 전에 개인정보 노출 주의 문구를 보여준다.
- 전화번호, 신분증, 카드번호, 얼굴 등 민감정보 노출 가능성을 안내한다.
- 사용자가 업로드한 사진은 삭제할 수 있어야 한다.

## 일행방 데이터 권한

- 일행방 데이터는 같은 일행방 구성원에게만 노출한다.
- 작성자는 본인이 만든 저장 위치, 사진, 분실물 제보를 수정/삭제할 수 있어야 한다.
- 같은 일행방 구성원의 수정/삭제 권한은 기능별로 명시적으로 정한 뒤 구현한다.

## 로그 금지 항목

다음 정보는 앱 또는 서버 로그에 남기지 않습니다.

- 정확한 위도/경도
- 전화번호
- 신분증 번호
- 카드번호
- API key
- access token 또는 refresh token
- 원본 사진 URL이 비공개 리소스에 직접 접근 가능한 경우의 전체 URL

## 관리자 접근

관리자 기능이 생기더라도 개인의 실시간 위치를 기본 노출하지 않습니다.

운영에 필요한 경우에도 집계 데이터, 만료된 데이터, 또는 익명화된 데이터부터 검토합니다.
